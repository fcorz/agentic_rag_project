# 技术栈知识点映射

本文件将 `docs/知识库项目计划.md` 的「技术栈规划」映射到本课程课时与当前项目源码。

| 技术领域 | 项目中已有实现 | 主要课时 | 学完后的掌握要求 |
|---|---|---|---|
| 模型调用 | `agent/providers.py`、`agent/prompts.py` | 10 | 会配置 OpenAI-compatible API、Responses API、模型名、Prompt |
| 文档解析 | `ingestion/extract_files.py` | 04 | 会把 PDF 转换为可检索文本，并理解 DOCX/Markdown/TXT 扩展方式 |
| 分块策略 | `ingestion/chunker.py` | 05 | 会实现 recursive chunking、理解 semantic chunking 和 parent-child chunking |
| 向量检索 | `sql/schema.sql`、`agent/db_utils.py` | 03、07 | 会使用 pgvector 存储和检索 embedding |
| 关键词检索 | `sql/schema.sql` 的 FTS 查询 | 08 | 会使用 PostgreSQL FTS 理解 BM25 思路 |
| 混合检索 | `hybrid_search` SQL 函数、`agent/tools.py` | 09 | 会融合向量分数和文本分数，并理解权重影响 |
| 查询理解 | 当前项目未显式拆分 | 13 | 会实现 query rewrite、intent detection 的最小 demo |
| Rerank | 当前项目未实现 | 14 | 会实现轻量规则 rerank 和 LLM rerank 思路 |
| Agent 编排 | `agent/agent.py`、`agent/api.py` | 12 | 会解释 Pydantic AI Agent 如何调用工具完成任务 |
| 工具调用 | `agent/agent.py`、`agent/tools.py` | 11 | 会定义 tool input schema、注册工具、解析工具调用 |
| 评测体系 | 当前项目测试较基础 | 15 | 会构建 golden set，记录召回与回答质量 |
| 可观测性 | 当前项目基础日志 | 15 | 会记录 trace log、prompt log、retrieval log |
| 安全 | 当前项目未系统实现 | 16 | 会设计权限过滤、Prompt Injection 防护、PII Masking |
| 工程交付 | `Dockerfile`、`docker-compose.yml`、部署文档 | 02、16 | 会用 Docker Compose 部署并解释环境变量差异 |

## 学习路线关系

```text
01-03：建立系统全景和基础设施理解
04-06：掌握文档入库链路
07-09：掌握检索链路
10-12：掌握模型调用和 Agent 工具链路
13-14：补齐进阶 RAG 能力
15-16：补齐评测、安全、可观测性和交付闭环
```
