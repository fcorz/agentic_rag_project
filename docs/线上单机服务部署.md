# 线上单机服务部署

本文用于将项目部署到一台 Linux 服务器上。推荐方式是 Docker Compose + Nginx 反向代理，适合个人演示、内部试用和小规模知识库服务。

## 部署目标

单机上运行：

- PostgreSQL + pgvector
- FastAPI API 服务
- Streamlit UI
- Nginx 反向代理

推荐访问方式：

| 服务 | 内部端口 | 对外方式 |
|---|---:|---|
| FastAPI | 8058 | `https://your-domain.example/api` 或仅内网访问 |
| Streamlit UI | 8501 | `https://your-domain.example/` |
| PostgreSQL | 5432 | 不建议公网暴露 |

## 1. 准备服务器

建议配置：

- Ubuntu 22.04 或更新版本
- 2 核 CPU
- 4 GB 以上内存
- 40 GB 以上磁盘

安装基础工具：

```bash
sudo apt update
sudo apt install -y git curl ca-certificates nginx
```

安装 Docker：

```bash
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
```

重新登录服务器后验证：

```bash
docker version
docker compose version
```

## 2. 拉取代码

```bash
sudo mkdir -p /opt/agentic-rag
sudo chown -R $USER:$USER /opt/agentic-rag
cd /opt/agentic-rag
git clone <your-repository-url> .
```

如果是直接上传代码，保证最终代码位于：

```text
/opt/agentic-rag
```

## 3. 创建生产环境变量

```bash
cat > .env <<'EOF'
APP_ENV=production
LOG_LEVEL=INFO
APP_HOST=0.0.0.0
APP_PORT=8058
API_URL=http://api:8058

SERVER_PORT=8501
SERVER_HOST=0.0.0.0

DB_USER=postgres
DB_PASSWORD=change_this_strong_password
DB_HOST=postgres
DB_PORT=5432
DB_NAME=vector_db

OPENAI_API_KEY=your_openai_api_key
OPENAI_BASE_URL=https://cc.addcn.com/droid/claude
OPENAI_API_MODE=responses
LLM_CHOICE=gpt-4o-mini
EMBEDDING_MODEL=text-embedding-3-small
EOF
```

生产环境注意：

- 修改 `DB_PASSWORD`。
- 不要把 `.env` 提交到 Git。
- 如果使用 OpenAI-compatible 模型网关，配置 `OPENAI_BASE_URL`；如果直接使用 OpenAI 官方接口，可以删除该变量。
- 如果模型网关只支持 OpenAI Responses API，配置 `OPENAI_API_MODE=responses`；默认值是 `chat`，会调用 `/chat/completions`。
- 不建议对公网开放 PostgreSQL 端口。

## 4. 调整 Compose 暴露端口

当前 `docker-compose.yml` 会把 API、UI 和 PostgreSQL 映射到宿主机端口。线上更稳妥的做法是：

- 只让 Nginx 对外暴露 80/443。
- API 和 UI 可以只监听本机或 Docker 网络。
- PostgreSQL 不对公网开放。

如果暂时用于演示，可以保留默认端口，但需要在云服务器安全组中只开放：

```text
80
443
```

如果确实要直接访问调试端口，再临时开放：

```text
8058
8501
```

## 5. 启动服务

```bash
cd /opt/agentic-rag
docker compose up -d --build
docker compose ps
```

验证 API：

```bash
curl http://127.0.0.1:8058/health
```

执行文档入库：

```bash
docker compose exec api python -m ingestion.ingest --documents documents/ --clean
```

## 6. 配置 Nginx

创建 Nginx 配置：

```bash
sudo tee /etc/nginx/sites-available/agentic-rag >/dev/null <<'EOF'
server {
    listen 80;
    server_name your-domain.example;

    client_max_body_size 50m;

    location / {
        proxy_pass http://127.0.0.1:8501;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8058/;
        proxy_http_version 1.1;
        proxy_buffering off;
        proxy_cache off;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
EOF
```

启用配置：

```bash
sudo ln -sf /etc/nginx/sites-available/agentic-rag /etc/nginx/sites-enabled/agentic-rag
sudo nginx -t
sudo systemctl reload nginx
```

访问：

```text
http://your-domain.example/
http://your-domain.example/api/health
```

## 7. 配置 HTTPS

如果服务器绑定了域名，可以使用 Certbot：

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.example
```

证书续期通常由 Certbot 自动安装定时任务。检查续期：

```bash
sudo certbot renew --dry-run
```

## 8. 日常运维命令

查看服务：

```bash
docker compose ps
```

查看日志：

```bash
docker compose logs -f api
docker compose logs -f ui
docker compose logs -f postgres
```

重启服务：

```bash
docker compose restart api ui
```

更新部署：

```bash
git pull
docker compose up -d --build
docker compose logs -f api
```

备份数据库：

```bash
mkdir -p backups
docker compose exec -T postgres pg_dump -U postgres vector_db > backups/vector_db_$(date +%Y%m%d_%H%M%S).sql
```

恢复数据库：

```bash
cat backups/vector_db.sql | docker compose exec -T postgres psql -U postgres vector_db
```

## 9. 安全建议

- 使用强密码替换默认 `DB_PASSWORD`。
- 不要把 PostgreSQL 端口暴露到公网。
- API 如果对公网开放，应增加认证、限流和日志审计。
- `.env` 权限建议设置为仅当前用户可读：

```bash
chmod 600 .env
```

- 云服务器安全组只开放必要端口。

## 10. 排障检查表

服务是否启动：

```bash
docker compose ps
```

API 是否健康：

```bash
curl http://127.0.0.1:8058/health
```

Nginx 配置是否正确：

```bash
sudo nginx -t
sudo journalctl -u nginx -n 100 --no-pager
```

数据库是否可用：

```bash
docker compose exec postgres pg_isready -U postgres -d vector_db
```

OpenAI Key 是否注入容器：

```bash
docker compose exec api sh -lc 'test -n "$OPENAI_API_KEY" && echo ok'
```
