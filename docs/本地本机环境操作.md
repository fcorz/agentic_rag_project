# 本地本机环境操作

本文用于在开发电脑上直接运行 Agentic RAG 项目。适合学习源码、调试 API、观察入库和检索链路。

## 适用场景

- 你希望在 IDE 中调试 Python 代码。
- API 和 Streamlit UI 运行在本机 Python 环境中。
- PostgreSQL 可以使用本机安装版本，也可以只用 Docker 启动数据库。

## 前置条件

- Python 3.12
- Docker 和 Docker Compose
- OpenAI API Key
- uv

安装 uv：

```bash
pip install uv
```

## 1. 准备 Python 环境

在项目根目录执行：

```bash
python -m venv .venv
source .venv/bin/activate
uv pip install -e .
```

如果你的 Python 版本不是 3.12，建议先切换 Python 版本再创建虚拟环境。

## 2. 准备数据库

本机开发推荐只启动 PostgreSQL 容器：

```bash
docker compose up -d postgres
docker compose ps postgres
```

当前 `docker-compose.yml` 将容器内 PostgreSQL 的 `5432` 映射到本机 `6543`。所以本机 Python 进程连接数据库时应使用：

```text
DB_HOST=localhost
DB_PORT=6543
```

## 3. 创建环境变量

在项目根目录创建 `.env`：

```bash
cat > .env <<'EOF'
APP_ENV=development
LOG_LEVEL=INFO
APP_HOST=0.0.0.0
APP_PORT=8058
API_URL=http://localhost:8058

SERVER_PORT=8501
SERVER_HOST=0.0.0.0

DB_USER=postgres
DB_PASSWORD=postgres
DB_HOST=localhost
DB_PORT=6543
DB_NAME=vector_db

OPENAI_API_KEY=your_openai_api_key
OPENAI_BASE_URL=https://cc.addcn.com/droid/claude
OPENAI_API_MODE=responses
LLM_CHOICE=gpt-4o-mini
EMBEDDING_MODEL=text-embedding-3-small
EOF
```

注意：如果 API 和 UI 都在本机运行，`API_URL` 使用 `http://localhost:8058`。
如果使用 OpenAI-compatible 模型网关，配置 `OPENAI_BASE_URL`；如果直接使用 OpenAI 官方接口，可以删除该变量。
如果模型网关只支持 OpenAI Responses API，配置 `OPENAI_API_MODE=responses`；默认值是 `chat`，会调用 `/chat/completions`。

## 4. 启动 API 服务

```bash
source .venv/bin/activate
uvicorn agent.api:app --host 0.0.0.0 --port 8058 --reload
```

验证健康检查：

```bash
curl http://localhost:8058/health
```

预期返回：

```json
{
  "status": "healthy",
  "database": true,
  "llm_connection": true
}
```

## 5. 执行文档入库

把 PDF 文件放到 `documents/` 目录，然后执行：

```bash
source .venv/bin/activate
python -m ingestion.ingest --documents documents/ --clean
```

常用参数：

| 参数 | 说明 |
|---|---|
| `--documents documents/` | 指定 PDF 文件目录 |
| `--clean` | 入库前清空已有文档、分块、会话和消息 |
| `--chunk-size 850` | 设置分块大小 |
| `--chunk-overlap 150` | 设置分块重叠长度 |
| `--no-semantic` | 关闭语义分块，使用递归字符分块 |
| `--no-images` | 跳过图片解析 |
| `--no-tables` | 跳过表格解析 |

入库完成后可以查看文档列表：

```bash
curl http://localhost:8058/documents
```

## 6. 启动 Streamlit UI

打开另一个终端：

```bash
source .venv/bin/activate
streamlit run ui/app.py --server.port=8501 --server.address=0.0.0.0
```

浏览器访问：

```text
http://localhost:8501
```

## 7. 调用问答接口

普通问答：

```bash
curl -X POST http://localhost:8058/chat \
  -H "Content-Type: application/json" \
  -d '{
    "message": "请总结这些报告中的核心内容",
    "user_id": "local-user",
    "search_type": "hybrid"
  }'
```

向量检索：

```bash
curl -X POST http://localhost:8058/search/vector \
  -H "Content-Type: application/json" \
  -d '{
    "query": "sustainability strategy",
    "limit": 5
  }'
```

混合检索：

```bash
curl -X POST http://localhost:8058/search/hybrid \
  -H "Content-Type: application/json" \
  -d '{
    "query": "sustainability strategy",
    "limit": 5
  }'
```

## 8. 运行测试

```bash
source .venv/bin/activate
pytest
```

指定测试：

```bash
pytest tests/agent/test_models.py
pytest tests/ingestion/test_chunker.py
```

## 常见问题

### API 无法连接数据库

确认本机环境变量使用的是本机映射端口：

```text
DB_HOST=localhost
DB_PORT=6543
```

检查数据库容器：

```bash
docker compose ps postgres
docker compose logs postgres
```

### UI 无法连接 API

确认 `.env` 中：

```text
API_URL=http://localhost:8058
```

如果 UI 侧边栏中 API URL 不是该地址，手动改为 `http://localhost:8058` 后点击健康检查。

### 文档入库很慢

Docling 解析 PDF、语义分块和 embedding 都可能耗时。开发阶段可以先用少量 PDF 验证流程，也可以加 `--no-semantic` 降低分块成本。
